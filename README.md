# About

This is homebrew repo for my personal tap. It contains formulae for software that I use and want to be able to install easily on any machine.

# Usage
To use this tap, run the following command:

```bash
brew tap mikart143/tap
```

After that, you can install any of the formulae in this tap using `brew install <formula>`. For example, to install `rusted-tools`, you would run:

```bash
brew install rusted-tools
```

# Formulas

- [rusted-tools](https://github.com/mikart143/rusted-tools) - A rust made tool for mcp proxying
